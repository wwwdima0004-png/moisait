## Техническое SEO

| Нашёл | Исправил |
| --- | --- |
| Одна общая пара title/description на весь сайт, нет canonical, OG без картинки, нет Twitter cards | Уникальные title, description и canonical для каждой страницы, Open Graph и Twitter cards (`src/lib/seo.ts`), `metadataBase`, `lang="ru"` |
| Нет OG-изображения | Ч/б OG-картинка 1200×630 (`public/og-image.png`) на всех страницах |
| Нет sitemap.xml и robots.txt | `app/sitemap.ts` (все страницы, 7 услуг, 14 статей с датами) и `app/robots.ts` |
| Нет структурированных данных | JSON-LD: ProfessionalService (Бишкек, телефон, sameAs), WebSite, Service, BlogPosting, Blog, BreadcrumbList, FAQPage, ItemList |
| Нет мест под коды Search Console и Вебмастера | `verification` в `src/config/site.ts`, пустые значения не выводятся |
| Нет посадочных страниц под запросы | 7 страниц `/uslugi/...` (550–650 слов, FAQ, WhatsApp, ссылки на статьи) и индекс `/uslugi` |
| Блог — пустая заглушка | 14 статей (940–1000 слов) с оглавлением, FAQ, «Читайте также», «Услуги по теме» |
| Почти нет внутренних ссылок, направления на главной вели в Telegram | Перелинковка главная ↔ услуги ↔ статьи, хлебные крошки, меню и футер ведут на услуги и блог |
| Контент ниже hero рендерился с `opacity:0` (framer-motion) и был невидим без JS | Скролл-анимации убраны, контент виден сразу и полностью в HTML |
| Страницы портфолио и блога без canonical/OG | Исправлено через общий конструктор метаданных |

## Скорость

| Нашёл | Исправил |
| --- | --- |
| framer-motion (~40 КБ gzip) ради появления блоков | Пакет удалён, анимации hero на CSS, без JS |
| Hero, иллюстрация и секции были клиентскими компонентами | Всё, кроме шапки, — серверные компоненты, страниц с JS-логикой нет |
| 4 шрифта по 4–5 статических начертаний | Вариативные шрифты (один файл на набор символов), cyrillic + latin, вспомогательные шрифты без preload |
| Сдвиг вёрстки в статье из-за подмены моноширинного шрифта (CLS 0.117) | Мета-строки и крошки на основном шрифте, CLS 0 |
| — | Все страницы статические (SSG), без БД и рантайм-зависимостей, контент читается только при сборке |
