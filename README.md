# Pulse Tech — сайт студии разработки

Next.js 16 (App Router) + Tailwind CSS v4. Все страницы генерируются статически при сборке, база данных не нужна.

## Запуск

```bash
npm install
npm run dev     # разработка: http://localhost:3000
npm run build   # production-сборка
npm run lint
```

## Где что редактировать

- **`src/config/site.ts`** — контакты и ссылки (WhatsApp, Telegram, Instagram, телефон), город, описание, пункты меню, преимущества, этапы работы, кейсы портфолио и коды подтверждения Google Search Console / Яндекс Вебмастера (`verification`).
- **`src/content/services/*.md`** — страницы услуг `/uslugi/<имя-файла>`.
- **`src/content/blog/*.md`** — статьи блога `/blog/<имя-файла>`.
- **`public/og-image.png`** — картинка для соцсетей и мессенджеров.

## Как добавить статью

1. Скопируй любой файл из `src/content/blog/` и переименуй: имя файла станет адресом (латиница, через дефис).
2. Заполни frontmatter:

```md
---
title: Заголовок статьи (H1 и title)
description: Описание для поиска и соцсетей, до ~160 знаков
date: 2026-10-10
category: Стоимость
readingTime: 7
services: razrabotka-saytov-bishkek, telegram-boty-na-zakaz
related: skolko-stoit-telegram-bot, etapy-razrabotki-sayta
---
```

- `services` — slug-и услуг для блока «Услуги по теме»;
- `related` — slug-и статей для «Читайте также» (если пусто, подберутся по категории);
- `updated` — необязательная дата обновления.

3. Ниже — текст в Markdown: `## H2`, `### H3`, абзацы, списки `-` и `1.`, чек-листы `- [ ] пункт`, цитаты `>`, таблицы `| a | b |`, `**жирный**`, ссылки `[текст](/uslugi/...)`.
4. Раздел `## Частые вопросы` с вопросами в `### ...` превращается в FAQ-аккордеон и разметку FAQPage.

Статья автоматически появится в блоге, sitemap.xml, на главной (если она среди трёх самых свежих) и в «Читайте также».

## Деплой

`./deploy.sh` — локальная сборка и выкладка на сервер (см. комментарии в файле). Дополнительных настроек `next.config` проект не требует.
